# ObjectRemoverPlugin

OFX background remover for DaVinci Resolve. The current build supports optional **U2NetP AI
segmentation on CPU**, the original border-colour key, and optional manually painted PNG
corrections for the matte. See the
[Windows setup and test guide](docs/05-build-install-test-windows.md) for installation, logs and
limitations. The earlier AI build ran in Resolve on Windows; this new manual-mask feature still needs
Windows/Resolve testing. The reported playback crashes remain unproven fixed.
