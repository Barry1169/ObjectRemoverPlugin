# ObjectRemoverPlugin

OFX background remover for DaVinci Resolve. The current build supports optional **U2NetP AI
segmentation on CPU**, as well as the original border-colour key. See the
[Windows setup and test guide](docs/05-build-install-test-windows.md) for installation, logs and
limitations. AI inference has been tested with a real model on Linux; Windows/Resolve AI behaviour
and the reported playback crashes still need testing on the target machine.
