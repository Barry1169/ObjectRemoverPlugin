THIRD-PARTY LICENSES — AI Background Remover (AiBgRemover) OpenFX plugin
================================================================================

This file ships inside the plugin bundle, next to the .ofx binary:

    AiBgRemover.ofx.bundle/Contents/Win64/THIRD_PARTY_LICENSES.txt

It is written to be accurate rather than exhaustive-by-default. Each component is
labelled with whether it is actually redistributed in the bundle, because that is
what determines whether its licence imposes an obligation on you.

--------------------------------------------------------------------------------
SUMMARY — WHAT IS IN THE BUNDLE
--------------------------------------------------------------------------------

Current repository:

    AiBgRemover.ofx ................. this project, MIT
    THIRD_PARTY_LICENSES.txt ........ this file
    ONNX Runtime C API header ....... MIT (vendored source/header)

No runtime DLL or model weights are included in the plugin bundle. The optional
setup script separately downloads Microsoft's CPU ONNX Runtime and rembg's U2NetP
model into the user's checkout. See section 2 and section 5 for provenance,
license terms and unresolved weights licensing. No GPU provider is implemented.

Sections 3 and 4 describe possible future providers, not the current build.

4. NVIDIA CUDA RUNTIME AND cuDNN — PROPRIETARY — READ BEFORE SHIPPING
================================================================================

*** These are NOT open source. Sections 2 and 3 do not apply to them. ***

The CUDA build of ONNX Runtime needs cudart, cublas, cublasLt, cudnn and friends
on the DLL search path. They are covered by the NVIDIA Software License Agreement
and the cuDNN Software License Agreement, which permit redistribution only under
specific conditions — generally that the DLLs come from an NVIDIA redistributable
package, are unmodified, and are accompanied by NVIDIA's own licence text and
EULA, which the end user is bound by.

Consequences for this project, all still open:

  * The CUDA redistributables add roughly 1.5-3 GB to the install. That is why
    DirectML is brought up first even though CUDA is likely faster on an RTX 2050.
  * Shipping them requires including NVIDIA's EULA in this file or beside it, and
    a decision about whether the plugin is distributed at all versus built
    locally by each user.
  * Nothing in this repository has been checked against the current NVIDIA
    redistributable terms. Do that before distributing a CUDA-enabled bundle.

Until then the CUDA path is a local-build option, not a redistributable one.

5. MODEL WEIGHTS — LICENCE VARIES PER MODEL — NOTHING SHIPPED YET
================================================================================

No model file is redistributed by this project. The optional setup script downloads
rembg's U2NetP ONNX into the user's checkout under models\u2netp.onnx. The
U-2-Net source code uses Apache-2.0, but the terms for these particular exported
weights have not been independently confirmed; verify before redistribution or
commercial use. A SHA-256 match verifies the download, not its license.

What has been established about the candidates, and what has not:

    BiRefNet ............ code MIT. Weight licence for the specific published
                          checkpoint still needs confirming against the file you
                          actually download.
    RobustVideoMatting .. GPL-3.0. REJECTED: incompatible with an MIT plugin that
                          is loaded into a proprietary host.
    MODNet .............. code Apache-2.0, but a downstream project reports the
                          published weights as CC BY-NC-SA 4.0, which forbids
                          commercial use. Unresolved; do not ship until it is.
    ViTMatte ............ MIT.
    SAM 2 ............... Apache-2.0, but needs interactive prompts, so it does
                          not fit an automatic background remover.
    U^2-Net / IS-Net .... Apache-2.0 code; weight licence unconfirmed.

The U2NetP model is offered for this user-supplied local setup despite the
unresolved weights license; it is not bundled or claimed cleared for distribution.
MODNet illustrates why weight terms must not be inferred from code licensing.
